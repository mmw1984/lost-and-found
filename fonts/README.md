# Fonts

OpenRunde Regular and Medium were downloaded from the author's official
GitHub release (v1.0.1) and are included under the SIL Open Font License 1.1.
See `OFL-OpenRunde.txt`.

Exposure is a paid commercial typeface by Federico Parra Barrios, published
by 205TF. The project owner supplied these licensed webfont files:

- `Exposure-205TF-VAR.woff2`
- `Exposure-205TF-VAR-Italic.woff2`

The site references these exact filenames from `styles.css`. Keep proof of the
applicable 205TF webfont license with the project records; the font files must
not be redistributed beyond the license terms.

Official publisher: https://www.205.tf/
